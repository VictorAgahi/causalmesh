### Fixed
- `mesh-mcp graph --format fingerprint` no longer depends on the checkout directory: node, doc-section and property-source paths are fingerprinted as `<root index>:<path relative to that root>` with `/` separators instead of absolute paths, so the same content under the same `mesh-mcp.toml` gives the same fingerprint in any directory, on any machine or OS. Fingerprint values change once with this release. `NodeId`s and the persistent index cache are unaffected.
