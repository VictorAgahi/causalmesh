### Added
- `IndexHealth` now remembers every file the indexer rejected (oversized, binary, guard, parse
  failure), not just the counters: path, reason and size, sorted and deduplicated, capped at
  10,000 entries per snapshot.
- `smart_search` and `find_dependents` append a note when rejected files fall inside the
  query's scope (never for files outside it): up to 20 paths with reason and size, then
  "and N more", plus the action to take (read the file directly). The note is reserved before
  results are paginated, so it survives even when a results page fills the 48 KB output cap.
- `mesh-mcp doctor` reports the same index-health summary (counts per reason, first 10 paths).
