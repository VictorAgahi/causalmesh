### Added
- `mesh-mcp doctor --fix`: repairs an orphaned socket, socket/directory permissions, a corrupt
  or pre-4.4 legacy index cache, an orphaned per-version workspace cache directory left behind
  by a mesh-mcp upgrade, and stops a daemon running a different version than this `mesh-mcp` —
  never the audit trail, whose corruption is reported but never erased.
- `mesh-mcp doctor --json`: emits the repairable-health checks above as JSON on stdout, for
  install scripts, alongside the existing prose diagnostics on stderr.
- `mesh-mcp run` warns when the daemon it connects to is running a different version than
  itself (a daemon left over from before an upgrade), instead of silently serving from it.

### Changed
- The daemon's socket file is now `0600` and its parent directory `0700`, explicitly, whatever
  the process umask.
