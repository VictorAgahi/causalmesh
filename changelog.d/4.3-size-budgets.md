### Added
- Size-tier benchmark budgets (Plan 4 step 4.3): `scripts/bench/tier_bench.py` runs N cold `scale_bench.py` runs (fresh `HOME` each), reports medians with the load average of every run, proposes budgets (1.3 x median) and checks the median against a per-platform tier budget file. New `scripts/bench/budgets-50k.json` and `scripts/bench/budgets-200k.json`; measurements for 5k / 50k / 200k synthetic files and two real repositories in `docs/quality.md`.
- Nightly scale bench gains a 50k-file job (plain corpus and contract mix, 3 cold runs each, median against `budgets-50k.json`); the 200k tier stays manual.

### Changed
- `scale_bench.py` reports peak memory after the server exits (`/usr/bin/time -l` "peak memory footprint" on macOS, `getrusage` max RSS on Linux) instead of sampling `ps` RSS, records the indexed file count, gains `--no-budget` / `--no-reload`, and treats a reload probe that never sees its symbol as a failed measurement instead of a silent pass.
