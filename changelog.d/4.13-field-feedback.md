### Added
- `smart_search` can search every configured root at once: `scope` is now **optional** (schema
  change: it is no longer in `required`, and is typed `string | null`). Omitting it, or passing
  `"."`, `"*"` or the exact workspace root, searches all roots — in a multi-root workspace this
  used to fail with a sandbox-escape error (`-32602`) because the workspace root is only the
  roots' parent. The sandbox jail itself is unchanged: `/`, `$HOME` or any other enclosing
  ancestor is still rejected, and a global `fuzzy` scan never returns a file outside the roots.
- `scripts/bench/search_payload.py`: measures the real Markdown size of a `smart_search` page on
  the golden corpora.

### Changed
- A `smart_search` page now stops at 8 KiB of rendered results by default
  (`DEFAULT_PAGE_BUDGET_BYTES`, calibrated on measured golden-corpus pages, see
  `docs/quality.md` 2026-09-27); `limit` (default 20) is a secondary cap. The heaviest measured
  page drops from 15.4 KB to 9.8 KB; pages that were not cut by `limit` are unchanged.

### Fixed
- `mesh-mcp run` (proxy mode, Unix and Windows): if the proxy's own connection fails right after
  the daemon answered its liveness check, the session falls back to standalone mode instead of
  exiting.
- `mesh-mcp run` (proxy mode, Unix and Windows): when `meshd` dies mid-session the process now
  exits (status 1) so the client sees EOF, and logs the cause and the daemon log path on stderr.
  It used to stay alive with stdout open, waiting on stdin, with nothing logged.
