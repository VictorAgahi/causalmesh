### Added
- `scripts/install_pilot.sh`: idempotent pilot installer (macOS/Linux, x86-64/arm64). Installs
  `mesh-mcp` and `meshd` into `~/.local/bin` from `--bin-dir` or a local `cargo build --release`
  (no download), runs `mesh-mcp init --auto --write-ide-config` after confirmation (`--yes`),
  keeps an existing `.agents/mesh-mcp.toml`, and verifies with `mesh-mcp doctor --json`.
  `scripts/test_install_pilot.sh` runs it twice under an isolated `HOME` and requires an
  identical state; the release smoke-test CI job runs it.
- `mesh-mcp stats`: per-tool latency p50/p95 (nearest-rank), `isError` count and rate, index
  cache hit rate, and `meshd` restarts. Metrics a database written before this release lacks are
  reported as "not recorded", never as zero. Nothing is estimated (no "tokens saved").
- `docs/pilot-scorecard.md`: A/B measurement protocol and empty results grid for the pilot.

### Changed
- The audit database gains three metrics tables outside the SHA-256 chain: `tool_call_metrics`
  (latency per audited call), `index_cache_metrics` (cache lookups per indexing pass, which were
  in-memory only) and `process_starts` (one row per `meshd`/`mesh-mcp` process start).
  `verify_db` is unaffected.
