### Fixed
- Invalid tool arguments and RSAH governance refusals are now written to the audit log with
  status `ERROR`. Both used to leave `ToolRegistry::invoke` through an early return, before the
  audit write, so a refused call left no trace at all.
- `smart_search`'s rendered snippet is now wrapped in a code fence longer than the longest run of
  backticks it contains, so a snippet showing Markdown, a doc-comment example, or a raw string
  that itself contains a ```` ``` ```` line no longer closes the fence early and splits the
  snippet across the entry boundary.
- `WorkspaceIndexer::repo_names` now disambiguates two roots that share a directory name (e.g.
  `.../a/api` and `.../b/api`) with their parent directory segment, deterministically. They used
  to render the same display name and silently merge into one service in `visualize_mesh`.
- An unknown tool name during the first indexing pass now gets the same `-32602` it would once
  indexed, instead of a retry-able "still indexing" that never stopped being wrong for that name.
