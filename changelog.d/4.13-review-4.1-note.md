### Changed
- The `smart_search` not-indexed note (step 4.1) now names only rejected source files (a
  tree-sitter language or YAML), the same filter `find_dependents` already used: images,
  lockfiles and prose are no longer listed. On the golden corpora this removes 1.3–1.9 KB from
  every page, and the note disappears entirely from `bank-of-anthos` (measurements in
  `docs/quality.md`, 2026-09-27). `mesh-mcp doctor` still lists every rejected file.

### Fixed
- `smart_search`: a scope inside a configured root that reaches the workspace root only through
  a symlink was accepted as a global search; it is now rejected with `-32602` like any other
  symlink escape. Spellings that normalize to the workspace root (`./.`, `sub/..`, an absolute
  path through `..`) remain global.
